# Wellness · Huddle7

Panel web de seguimiento diario del wellness de las jugadoras: fatiga fisica, molestias, calidad del sueno y regla.

- Version publicada: https://raulabellon.github.io/wellness-huddle7/
- Uso: abre el enlace. Incluye datos de ejemplo; para datos reales se conecta a una hoja de Google Sheets.
- Guia completa: LEEME.md

Todo es local en el navegador; el unico origen de datos es la hoja de Google que configure el cuerpo tecnico.
